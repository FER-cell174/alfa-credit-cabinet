# Умный кредитный кабинет предпринимателя

Прототип цифрового кредитного конвейера для малого и микробизнеса (кейс Alfa Hack).
Предприниматель подаёт заявку онлайн и видит понятный статус; банк получает очередь, скоринг с объяснением и журнал решений.
Все данные синтетические, внешние источники (ЕГРЮЛ/ЕГРИП, ФНС, БКИ), подписание и выдача — моки. Доступа к системам Альфа-Банка нет.

## Что внутри

- **Кабинет клиента**: подбор продукта, мастер заявки из 4 шагов, трекер статуса, оферта, подписание (мок).
- **Кабинет банка**: очереди, карточка заявки со скорингом по факторам, запрос данных, решение аналитика, статистика, журнал аудита.
- **Конвейер**: проверка → обогащение (3 мок-источника, повтор при таймауте) → скоринг 100 баллов → решение.
  Исходы не бинарные: одобрение, другие условия, ручной разбор, отказ, запрос данных.
- **Автомат статусов** с проверкой допустимых переходов, историей и аудитом.
- **Без ИИ в решении**: кредитное решение детерминированное и объяснимое.

## Быстрый запуск

Нужны Docker и Docker Compose. Одна команда:

```bash
docker compose up --build
```

Откройте http://localhost:8080. Swagger: http://localhost:8080/api/docs.

Без Docker (SQLite, только API; нужны Python 3.12 и `pip install -r backend/requirements.txt`):

```bash
cd backend && uvicorn app.main:app --port 8000
```

## Проверка за 5 минут

Полный список сценариев: [docs/test-scenarios.md](docs/test-scenarios.md).

1. Войдите клиентом, выберите «Оборотный кредит» → «Подать заявку».
2. Выберите тестовую компанию «Ромашка-Опт» (ИНН 7701000002), выручка 14 000 000, прошлый год 13 000 000, сумма 5 000 000, срок 12.
3. Отправьте. Трекер сам дойдёт до «Другие условия»: 61 балл, класс B, 3 500 000 ₽ под 21%.
4. Примите оферту и подпишите договор: статус «Выдана (мок)».
5. Войдите аналитиком: в карточке видны проверки, вклад каждого фактора и история статусов.
6. Остальные исходы получаются другими ИНН:

| ИНН | Компания | Исход |
|---|---|---|
| 7701000001 | Север-Строй | одобрение |
| 7701000002 | Ромашка-Опт | другие условия |
| 7701000003 | ИП Тестов | нужны данные (без выручки) |
| 7701000004 | Гранит-Сервис | ручной разбор |
| 7701000005 | Лотос-Трейд | отказ, просрочка 90+ |
| 7701000006 | Вектор-Логистика | отказ, ликвидация |
| 7701000007 | Тайм-Аут | ручной разбор, БКИ не ответило |

Автоматически: `python scripts/smoke.py http://localhost:8080` (только стандартная библиотека Python).
Юнит-тесты бизнес-ядра: `cd backend && python -m unittest discover -s tests`.

## Настройка

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `JWT_SECRET` | значение из `.env.example` | секрет подписи токенов; для любой не демонстрационной среды замените |
| `DATABASE_URL` | SQLite-файл (в compose — PostgreSQL) | строка подключения SQLAlchemy |
| `MOCKS_URL` | пусто (в compose — `http://mocks:8001`) | адрес сервиса моков; пусто = моки внутри процесса API |
| `SEED_ON_START` | включено | создать демо-пользователей при старте |

Для compose скопируйте `.env.example` в `.env`, если хотите задать свой секрет.

## Требования к окружению

Обычный ПК с Docker (около 2 ГБ памяти, свободные порты 8080). Платных зависимостей нет, доступ к внешним сервисам при работе не нужен
(при сборке образов нужен доступ к реестрам Docker Hub, PyPI и npm). Версии зависимостей закреплены в `backend/requirements.txt`
и `frontend/package.json`, базовые образы — по точным тегам.

## Ограничения прототипа (честно)

- Скоринг — прозрачные правила, веса и пороги — допущения, без калибровки на реальных данных.
- Внешние источники, подписание и выдача — моки; файлы документов не хранятся, только метаданные.
- Обработка заявки идёт в фоне процесса API, без отдельной очереди; схема БД создаётся при старте, миграций нет.
- Автоматического истечения срока заявки нет.
- Проверка сборки: бизнес-ядро и 18 тестов прогнаны, фронтенд собран esbuild. Слой API, сборка Docker-образов и `scripts/smoke.py`
  были написаны в среде без доступа к PyPI/npm и **не запускались**. Перед сдачей выполните `docker compose up --build` и
  `python scripts/smoke.py http://localhost:8080`.
- `frontend/package-lock.json` не создан из-за отсутствия доступа к npm. Выполните `cd frontend && npm install` и закоммитьте файл
  (Dockerfile автоматически использует `npm ci`, если он есть).
